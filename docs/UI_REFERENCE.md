# 介面設計圖與實作範圍

設計圖先生成，再以原生 Compose 元件重建。相機預覽、錄音波形、檔名、照片及辨識文字皆來自操作中的資料。Android 的系統文件選擇器、權限視窗和通知框架由系統提供。

| 設計圖 | App 介面 |
| --- | --- |
| [錄音與播放](../screenshots/redesign/recording-player.png) | 工作台、拍照、儲存對話框、播放、照片檢視 |
| [錄音管理](../screenshots/redesign/library.png) | 列表、搜尋、回收桶、分類選擇及編輯 |
| [辨識與編輯](../screenshots/redesign/recognition-editor-settings.png) | 雲端及離線辨識、API 金鑰、音訊編輯、設定 |
| [帳號與小工具](../screenshots/redesign/account-and-widgets.png) | 引導、登入和授權、備份和更新、關於、桌面小工具 |

App 採暖白底、陶橘動作按鈕、深色媒體面板，以及共用的輪廓與圓角。小螢幕使用可捲動內容，保留錄音和匯出的固定操作區。設計圖中示意的功能與資料以 App 實際提供的操作為準。
