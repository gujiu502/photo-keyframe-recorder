照片關鍵幀錄音 v0.3.1 正式版，Android 10 及以上。

- 修復背景返回時波形按整段時間展開的問題：現在固定保留最多 100 個點，移除第二個麥克風讀取器，直接讀取錄音器音量。
- 長時間錄音使用前景服務與 CPU 喚醒鎖；儲存與錯誤處理移出主執行緒。遇到錄音器或資料庫錯誤時嘗試安全結束並保留原始資料。
- 降低相機預覽負擔，關鍵幀原圖仍為 1600×1200；小工具未安裝時不再每秒發送刷新廣播。
- 加入手機本地 Whisper：打開任一已完成錄音，選「本地識別」，可下載模型、開始／停止、選中文或自動語言，也可識別以前的項目。
- 首次自願下載約 74 MiB 的多語言 Tiny 模型，檢查 SHA-256；之後完全在手機離線識別。錄音不會傳送給識別伺服器。
- 分段解碼和保存結果，停止後保留已完成的文字；可導出 TXT，ZIP 的 Markdown 也包含識別文字。識別與錄音互相避讓。
- 保留啟動檢查 Drive 備份、外部刪除後自動补備份，以及任何頁面先返回錄音主頁、主頁再按返回才退到桌面的行為。

沿用正式簽名，可直接覆蓋升級；附 APK、SHA256SUMS.txt 和應用內更新清單。這是 GitHub 正式版本，並非預覽版。

Tiny 識別可能有誤字，請核對原音訊；記憶體不足時會提示重試並保留原件。實體手機的來電、耳機、廠商省電及低空間故障情境仍需實測。Google Drive 和 Google Play 的既有驗證範圍見 docs/IMPLEMENTATION.md。

已驗證：正式簽名 APK 的錄音、三張實際照片、暫停／背景返回、命名、ZIP 與異常退出恢復，以及舊項目識別、TXT、重啟持久化、ZIP 識別文字、CRC 與原音訊逐字節一致；兩項 Whisper 原生測試、七項資料庫測試、波形與重採樣單元測試、中文文案、Release lint、Direct APK、Play AAB、原簽名與16KiB頁面對齊通過。

長錄音測試結果：Android11／BlueStacks背景運行125分鐘未崩潰，返回後可繼續拍照並保存，十張照片的ZIP及完整音訊解碼通過。但實際音訊長約111分鐘，短於錄製計時，完整超兩小時音訊的檢查仍未通過，原因尚未確定。具體範圍見驗證文檔；不能據此宣稱實體手機兩小時錄音已完整驗證。

14項返回流程通過，包括Whisper視窗：先回錄音主頁，再按返回才退到桌面。

最終 Android14 完整設備流程及 v0.3.1 建置檢查均通過；包含實際相機／ZIP／恢復、14項返回、模型下載、舊錄音識別、TXT／重啟／ZIP和停止識別。詳見 [驗證文檔](https://github.com/gujiu502/photo-keyframe-recorder/blob/main/docs/IMPROVEMENTS.md)。

v0.3.1 修訂：識別文字的讀取、TXT／ZIP 導出、保存及永久刪除使用同一資料庫交易協調，避免讀取 AtomicFile 時影響未完成寫入。並行讀寫／導出與刪除保護、原生識別及停止、舊項目與ZIP介面回歸均通過。
