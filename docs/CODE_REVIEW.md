# v0.5.0 代碼審查

審查涵蓋 Android App、功能與資料模組、共用元件、建置及測試流程。優先追蹤錄音和照片持久化、MP4、雲端備份狀態、辨識、播放、編輯及 UI 操作的入口與資料路徑。第三方 Whisper 與 Riva 原始碼沿用既有固定來源。

| 問題 | 處理 |
| --- | --- |
| Drive 的手動重試可把已明確刪除的備份改成待上傳 | 讀取及重試寫入與 Drive 操作串行化，跳過已刪除或已完成的備份；加入已刪除狀態回歸案例 |
| 停用的開關列仍可點擊背景來變更值 | 對整列使用相同的停用條件 |
| 音訊長度用一天內的時間表示，24 小時以上不能顯示 | 列表、資訊視窗及小工具用時長格式，測試超過一天的值 |
| 播放滑桿可能保留初次渲染的回呼 | 滑桿沿用狀態並讀取最新的播放軌道及回呼 |
| 編輯頁使用固定偏移，小螢幕操作區容易互相覆蓋 | 改成可捲動的順序佈局，保留套用、撤銷及存檔功能 |
| Google 帳號本機狀態不完整時可能在畫面初始化就中止 | 讀取可用的帳號組合，檢查寫入是否成功 |
| NVIDIA 金鑰視窗的 Android 返回行為不一致 | 返回先回錄音工作台，明確點選取消則關閉金鑰視窗 |

既有長錄音驗證的時長缺口仍需獨立長時間測試。此版的展示格式修正與短錄音回歸不證明錄製兩小時的媒體時長正確。
